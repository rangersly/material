# TCP/IP 分层模型

## 一句话

网络通信就是把数据从一台机器的应用交给另一台机器的应用，分层是为了让每一层只关心自己的事。

## 四层模型

|层|作用|常见协议|排障关注|
|---|---|---|---|
|应用层|提供具体服务|HTTP、HTTPS、DNS、SSH、SMTP|域名、端口、服务是否响应|
|传输层|端到端传输|TCP、UDP|端口、连接状态、丢包重传|
|网络层|跨网段寻址和路由|IP、ICMP|IP、路由、网关、`ping`|
|链路层|同一局域网内传输|Ethernet、ARP、Wi-Fi|网卡、MAC、交换机、网线|

OSI 七层是教学模型，实际排障按上面四层理解就够了。

## 封装过程

```text
应用数据
→ TCP/UDP 头 + 数据（段/报文）
→ IP 头 + 数据（包）
→ 以太网头 + 数据 + FCS（帧）
```

发送时逐层加头，接收时逐层拆头。

## 两个关键设备

- **交换机**：同一局域网内按 MAC 地址转发
- **路由器**：不同网段之间按 IP 路由转发
- **默认网关**：本机不知道目标怎么走时，交给它

## 排障顺序

1. 链路：`ip link`，检查网线或 Wi-Fi
2. 地址：`ip a`
3. 路由：`ip r`
4. 连通性：`ping`
5. 端口和服务：`ss -tlunp`
6. DNS：`dig`
7. HTTP：`curl -v`
