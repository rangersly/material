# 常见端口速查

## 端口范围

|范围|说明|
|---|---|
|`0-1023`|系统端口，通常需要 root 才能监听|
|`1024-49151`|注册端口，常见服务默认使用|
|`49152-65535`|动态/临时端口，客户端通常从这里分配|
